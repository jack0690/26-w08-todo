# ✅ To-Do 리스트

> 이 README는 실습을 완성한 뒤, 배포 직전 단계에서 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 소개

이 프로젝트는 사용자가 일상적인 할 일을 효율적으로 관리할 수 있도록 제작된 클래식 To-Do 리스트 웹 애플리케이션입니다. Tailwind CSS(또는 Bootstrap)를 활용해 깔끔하고 직관적인 UI를 제공하며, 별도의 서버 없이 브라우저 내에서 가볍고 빠르게 동작합니다.

## 어떻게 만들었나요

AI와의 체계적인 협업 프로세스를 거쳐 제작되었습니다. 단발성 프롬프트 입력 방식에서 벗어나, PRD 작성과 구현 계획(Plan) 검증 단계를 거쳐 완성도를 높였습니다

## Bootstrap vs Tailwind

선택한 프레임워크: Tailwind CSS

선택한 이유: HTML 마크업 안에서 유틸리티 클래스를 조합해 컴포넌트 디자인을 빠르고 세밀하게 커스터마이징할 수 있어 선택했습니다.
